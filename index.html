Curso visual e interactivo · Desarrollo de software

Un sitio de muchas páginas que se mantiene solo con texto

Con cinco páginas, copiar y pegar el menú en cada archivo funciona. Con cincuenta, cada cambio es una tarde perdida. Jekyll arma el sitio a partir de plantillas, datos y Markdown, y GitHub Pages lo publica gratis cada vez que guardas un cambio. Este curso enseña a construirlo y a pedirle a un asistente de IA que lo amplíe sin desordenarlo.

Cómo usar este curso

Estado. El curso está en preparación. La tabla de contenido ya tiene los 16 capítulos con sus secciones y sus laboratorios, y está en revisión.

Para quién es. Para quien ya sabe hacer una página con HTML y CSS (el curso Páginas web basta) y quiere un sitio personal, un blog, la documentación de un proyecto o un catálogo que crezca sin repetir código. No hace falta saber Ruby: Jekyll se usa, no se programa.

Cómo está hecho. Un mismo sitio crece en todo el curso: un portafolio con blog y un catálogo de proyectos que sale de un archivo de datos. El mismo sitio donde lees este curso es un ejemplo real que se desarma por dentro. Los laboratorios son editores en vivo: cambias una plantilla, un dato o un prompt y ves la página o la estructura de archivos que resulta.
